Van Gogh Multilingual Canvas

This component intelligently switches between left-to-right and right-to-left layouts. In LTR mode, it uses margin-left and border-top-left-radius. In RTL mode, it uses margin-right and border-top-right-radius.

The :dir() pseudo-class enables true internationalization without JavaScript.
